# Step 7 · Go-To-Market

Author: Ramprasad · 2026-09-11 · Status: ACTIVE

## 1. Motion summary

**Developer-first wedge → design-partner platforms → ecosystem default.**
Sell the guarantee where trust is the product; let the open repo do the
top-of-funnel.

## 2. Phase GTM-0 — Validation (now → Q4 2026, alongside P1)

- 20 discovery interviews per `04-customers.md` §5 with kill criteria.
- ETHOnline 2026 finale (submission deadline Sept 13, 2026 — see
  `docs/SUBMISSION.md`) as a credibility event: demo video, live evidence.
- Developer onboarding audit: a stranger must go repo-clone → agent loop →
  paid signal in < 30 minutes with only README + `PROMPT.md`. Measure and
  fix the drop-off (this is the real "conversion funnel" today).
- 3 design-partner pilots signed (LOIs) from ICP 1/2.

## 3. Phase GTM-1 — Seed the rail (mainnet launch, H1 2027)

- **Channel 1 — agent ecosystems**: x402/Agent.market-style marketplaces,
  agent framework plugins (SDK from P2). Integration = distribution.
- **Channel 2 — open source**: hackathons with the mandate-escrow as a
  primitive; grants for integrations; `PROMPT.md` as viral artifact (any
  agent can self-onboard).
- **Channel 3 — content/evidence**: publish the whitepaper, audit reports,
  incident case studies ("how a mandate survived a prompt injection") —
  trust content for a trust product.
- **Channel 4 — founder-led sales**: 50 target accounts (ICP 1/2), evidence-
  first demos on staging with real workloads.
- Launch metric: 100 externally-funded tasks settled in first mainnet
  quarter; 10 paying Signal subscribers.

## 4. Phase GTM-2 — Default rail (H2 2027+)

- Partnership motion with payment facilitators and agent platforms (the
  complement posture from `03-competition.md` §2A).
- Marketplace v2 with payment-grounded reputation — the flywheel: settled
  tasks → agent reputation → more hires → more settled tasks.
- Enterprise pipeline (ICP 4) built on evidence/compliance packaging (R3).

## 5. Positioning assets

- One-liner: **"Agents can't transact without identity, data, and money —
  varanasi is where all three meet a check at settlement."**
- Proof pack: `docs/DEMO.md` (tx-linked), test dashboard, audit reports.
- Anti-pitch honesty: we publish our accepted risks and test debt — this is
  deliberately part of the brand for a security product.

## 6. Community & comms

- Weekly public changelog; granular commits (repo convention).
- X/Farcaster for releases; long-form on the blog; docs as product.
- Support SLA tiers only for paid R2/R3; community Discord for the rest.

## 7. GTM metrics

Funnel: repo clones/visits → agent-loop completions (telemetry-free proxy:
receipts on testnet) → design-partner convos → pilots → paid.
North-star: settled task volume (see `13-metrics.md`).
